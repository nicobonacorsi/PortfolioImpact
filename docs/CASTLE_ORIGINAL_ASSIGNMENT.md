## Option 1: Scenario analysis

Users want to know what could hit their portfolio. Build a system that takes a portfolio and:

1. Finds the geopolitical and macro events most likely to move it.
2. Puts a probability on each event, using prediction markets where relevant.
3. Estimates how much the portfolio would gain or lose if each event happens.

Count what people hold through ETFs: someone who owns QQQ also owns NVIDIA. Prediction markets rarely ask exactly the question you care about (“tariffs of 25% or more by March 31”), so show how you match events to markets and when you decide nothing fits. Consider the fact that today's prices already price (some?) of these events.
